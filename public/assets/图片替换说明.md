# 游戏图片替换说明

所有图片都在这个目录中。保持原文件名覆盖图片，通常不需要修改代码。
跑酷场景的文件名也集中在 `app/game/game-assets.ts`，可以在那里改成新文件名。

## 跑酷主画面

| 作用 | 当前文件 | 建议格式 |
|---|---|---|
| 天空 / 城市远景 | `run_bg_city_reference.png` | 竖版 JPG 或 PNG，不需要透明 |
| 地平线雾 / 可选云层 | 默认由程序绘制全宽蓝白雾墙 | 可选透明 PNG；只作为雾中的轻微纹理 |
| 道路两侧城市 | `roadside_city.png` | 透明 PNG；建筑为主、树木穿插，建议保持横向精灵条 |
| 胜利终点演唱会 | `concert_stage.png` | 透明 PNG，只保留舞台 |
| 玩家角色 | `player_fan.png` | 透明 PNG，人物居中、脚底贴近底边 |
| 粉色门票 | `collectible_lightstick.png` | 透明 PNG |
| 蓝色应援棒 | `collectible_ticket.png` | 透明 PNG |
| 磁铁 | `buff_magnet.png` | 透明 PNG |
| 指路牌 / 路障 | `obstacle_construction_sign.png` | 透明 PNG，竖立在赛道中央（左右滑动躲避） |
| 扁音响 | `obstacle_speaker.png` | 透明 PNG，竖版即可；游戏内会自动旋转 90° 横放在地面（跳跃通过） |
| 高横幅 | 目前由程序绘制 | 不需要图片，程序绘制两根霓虹立柱撑起的横幅（滑铲通过） |
| 黑色道路 | 目前由程序绘制 | 不需要图片 |

## 替换注意

- 角色、道具、障碍和舞台建议使用透明 PNG。
- 图片四周尽量不要留太多透明空白，否则游戏里会显得偏小。
- 同类图片尽量保持相似长宽比，避免视觉尺寸突然变化。
- 默认雾墙无需图片；宽度、颜色、位置、高度和浓度在 `view-tuning.ts` 中调整。
- `horizonFogWidthRatio` 控制雾墙宽度：`1` 为全宽，数值越小两侧建筑露出越多。
- 道路尽头的泛白距离和浓度分别调整 `roadFogStartDepth`、`roadEndFogOpacity`。
- 如果提供云层图片，应只包含云且背景透明，图片只会作为雾中的轻微纹理。
- 人物大小在 `view-tuning.ts` 中调整 `playerScale`。
- 门票、磁铁和应援棒大小统一调整 `collectibleScale`。
- 音响、路障和横幅大小统一调整 `obstacleScale`。
- 两侧建筑大小和密度分别调整 `roadsideBuildingScale`、`roadsideBuildingSpacing`；
  间距越小，建筑排列越密。
